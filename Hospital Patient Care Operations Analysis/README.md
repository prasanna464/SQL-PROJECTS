# Hospital Patient Care Operations Analysis 🏥📊

## 📌 Project Overview

Hospital Patient Care Operations Analysis is a MySQL-based database
and data analytics project designed to analyze hospital operations
and generate meaningful business insights using SQL.

## 🎯 Objectives

- Design a relational hospital database
- Establish relationships using Primary Keys and Foreign Keys
- Analyze patient and appointment data
- Analyze treatment performance
- Analyze doctor workload
- Analyze room and equipment utilization
- Identify operational problems
- Generate data-driven business insights

## 🗄️ Database Structure

The database contains five main tables:

1. Patients
2. Doctors
3. Rooms
4. Appointments
5. Treatments
